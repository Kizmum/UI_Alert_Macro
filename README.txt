UI ALERT MACRO v5.2
===================

1. Extract this archive fully. Keep the ui/ folder next to ui_alert_macro_gui.py.
2. Windows + Python 3.13: run install.bat, then start.bat.
3. Set a Discord webhook and role IDs in Settings and Other.
4. Enable the biomes you want to track and adjust the detection regions in Main.
5. F1 starts all enabled workspaces, F2 stops all. START/STOP in Main affects only the selected workspace.
